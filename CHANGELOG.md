## 1.3.0-beta.1

- Added local OpenAPI 3.0/3.1 JSON and YAML input with `--spec`.
- Added remote OpenAPI input, protected headers, and live polling with `--spec-url`.
- Added structural validation, internal `$ref` expansion, size and timeout limits, and last-valid reload behavior.
- Expanded the development proxy to support API paths without an `/api` prefix.
